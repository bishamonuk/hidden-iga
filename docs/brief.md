2. 【要確認】英国側：海外不動産の紹介でも、英国の Estate Agents Act・マネロン規制（HMRC の監督登録）の対象になるか確認。
3. 【要確認】写真・説明文の掲載許可：伊賀市 空き家対策課（0595-22-9676）へ。
4. 【要確認】空き家バンクの利用者登録の要件（海外在住者・外国籍の可否、移住目的の要否）。
